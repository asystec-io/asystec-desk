Al instalar Asystec Desk para Windows, la opción **Agregar el ID y el nombre de esta PC a la libreta de soporte de Asystec** viene marcada. La PC aparece en la libreta de la cuenta `asystec` cuando el servidor verifica el ID. El cliente puede desmarcar la opción durante la instalación.

Si falta conexión, Windows reintenta automáticamente. Al reinstalar, se conservan el alias y las notas que ya haya guardado soporte. La contraseña de acceso remoto permanece en la PC.
