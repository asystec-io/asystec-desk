Asystec Desk incorpora una libreta personal que sincroniza equipos, alias, etiquetas y notas entre las PC donde se inicia sesión con la misma cuenta. Los cambios sin conexión se conservan para enviarlos al reconectar.

El instalador para Windows x64 configura la API HTTPS de Asystec. Para probarla, instala el paquete en dos PC, abre Libreta e inicia sesión con la misma cuenta. Las contraseñas de acceso remoto permanecen bajo el control de cada equipo.

Se publica el mismo instalador verificado en Windows Sandbox. Conserva la identificación interna 0.1.3 del empaquetador y no lleva firma Authenticode. La etiqueta de esta publicación es v0.1.4.
